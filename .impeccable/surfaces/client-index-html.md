# GundHere Search Client

- Mode: Operate.
- Audience: Gunpla hobbyists searching from imperfect memory, partial names, or retailer terminology.
- Job: Submit a query, optionally constrain grade/scale/availability, scan canonical candidates, inspect ranking evidence, and open real retailer listings.
- Content proof: Real SQLite entity counts, canonical names, retrieval provenance, component scores, score margin, relationship metadata, and indexed listing data only.
- Constraints: Plain HTML/CSS/JavaScript, same-origin Python API, keyboard and mobile support, no crawling during search, no fabricated prices or availability.
- Direction: A hobby-shop inspection bench with cool measured work surface, ruled inventory labels, safety-orange selection marks, and a sticky evidence sheet.
- Memorable moment: FTS5 and vector candidate counts visibly merge into a unique rack, then the selected kit receives a scored inspection sheet.
- Unresolved: Automatic-match versus manual-review thresholds remain intentionally unclaimed until evaluation on reviewed queries.
